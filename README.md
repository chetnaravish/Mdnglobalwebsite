## About the Project

MDN Global School Kaithal is a CBSE affiliated school offering education from Nursery to Class XII, with over 20 years of excellence. This website was designed and developed to give parents and students a modern, smart and easy way to explore the school online.

Along with the usual school information, the website includes smart features like an **AI chatbot** and an **interactive robot tour**, which make the visitor experience more engaging.

##  Features

-  **AI Chatbot:** Visitors can ask questions about the school and get instant answers
-  **Interactive Robot Tour:** A guided virtual tour that introduces the school in a fun and modern way
-  **SEO Optimized:** Proper title, meta description, keywords and social sharing preview, so that the school can be found easily on Google
-  **Responsive Design:** Works smoothly on mobile, tablet and desktop
-  **Fast Deployment:** Hosted on Vercel for quick loading

##  Built With

- **Development approach:** Vibe coding with AI tools and prompt engineering
- **Hosting:** Vercel
- **Version control:** Git and GitHub

##  SEO Highlights

The website is set up to rank for local searches like *"best CBSE school in Kaithal"* and *"school admission Kaithal"*, using:

- Optimized page title and meta description
- Relevant keywords for Kaithal and Haryana
- Open Graph and Twitter preview cards for better sharing
- Theme color and mobile friendly viewport settings
